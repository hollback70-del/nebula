# Advanced Crypto Engine

Created by **nebula**. A secure cryptographic engine built in Python utilizing PBKDF2, Fernet symmetric encryption, and HMAC integrity checks.

## Installation
```bash
pip install advanced-crypto-engine-nebula
Usage Example

from advanced_crypto import AdvancedCryptoEngine

crypto = AdvancedCryptoEngine("my_secure_password", "my_passkey")
encrypted = crypto.encrypt_data("Hello Nebula!")
print(encrypted)
